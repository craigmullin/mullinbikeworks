# Mullin Bike Works

A simple static site for neighborhood bicycle refreshes in Northern Kentucky.

## Preview

Run `python3 -m http.server 8000` in the repository, then open `http://localhost:8000`.

## Publishing

Deploy the repository root as a static site. Point `mullinbikeworks.com` to your chosen host after testing. The contact page uses a `mailto:` link, which opens the visitor's email app; it does not submit a server-side form.

## Before launch

Confirm the email alias `craig@mullinbikeworks.com` receives mail. Review the service area and pricing copy. Add your hosting configuration and domain DNS settings.
